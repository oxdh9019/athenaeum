## 三、测试场景

### 场景 1: 完整用户流程
```
1. 打开浏览器 → http://localhost:8000
2. 验证页面加载 → Dashboard 默认显示
3. 点击"创建世界" → API 调用成功
4. 填写角色信息 → 艾丽娅 / 图书管理员
5. 点击"添加角色" → 角色出现在列表
6. 再创建一个角色 → 马克 / 咖啡师
7. 点击"启动世界" → 世界引擎启动
8. 切换到"对话" Tab
9. 选择两个 Agent
10. 点击"开始对话" → 对话触发
11. 验证对话历史显示
12. 切换到"灵魂" Tab → 选择角色查看灵魂
13. 切换到"地图" Tab → 查看地点可视化
14. 点击"■ 停止" → 服务器关闭
```

### 场景 2: 世界工坊流程
```
1. 切换到"工坊" Tab
2. 输入世界描述
3. 选择角色数量（4）
4. 点击"开始生成"
5. 等待 LLM 生成（可能失败）
6. 如成功：验证世界信息显示
7. 验证角色卡片网格
8. 验证 Big Five 雷达图
9. 验证关系图谱
10. 点击"应用到引擎"
11. 验证成功提示
```
